# Starter Battle: Open Field

Version 0.1 (draft). A small head-to-head battle for learning Wartable and testing the core rules. Uses the [Core Rules](core-rules.md) with the settings below.

## At a glance

| Setting | Value |
| --- | --- |
| Players | 2: **North** and **South** |
| Map | 12 columns × 10 rows (A1 to L10), open ground |
| Deployment zones | North: rows 1–2. South: rows 9–10. |
| Default facing on deploy | North faces S. South faces N. |
| Capacity | 60 per side |
| Units allowed | Infantry (10), Cavalry (20), Artillery (15) |
| Turn limit | 12 turns |
| Tie-break | North holds it at the start of the game |

The map is flat-topped hexes; even columns (B, D, F …) sit half a hex lower (see Core Rules 2.1). Every hex is open ground. There is no terrain and there are no barriers.

## Armies

Each player chooses units with a total Cost of **60 or less** and gives each a unique name (e.g. "1st Foot", "2nd Horse", "1st Guns"). Players reveal their army lists before turn 1.

A suggested army for first games (both players using it makes a fair mirror match):

| Suggested army | Cost |
| --- | --- |
| 2 Infantry | 20 |
| 1 Cavalry | 20 |
| 1 Artillery | 15 |
| **Total** | **55** |

## Setup

All units start off the map. On turn 1 (and later turns), units enter with **Deploy** orders into their own deployment zone.

## Rules in play

All Core Rules apply except:

- **No terrain or barriers.**
- **No passive orders** (artillery does not limber up automatically).
- **No reinforcements.** Destroyed units do not come back.

## Winning

1. **Annihilation.** A player wins immediately when the opponent has no units on the map and none left to deploy.
2. **Turn limit.** If no one has won by the end of turn 12, each player scores the Cost of their surviving units, counting half-strength units at half Cost (rounded down). The higher score wins. Equal scores are a draw.

The turn limit is a suggestion to stop games stalling; adjust it after playtesting.
